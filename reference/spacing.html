Spacing

Luft er en del av uttrykket. Skalaen holder rytmen lik fra knapp til seksjon, på store skjermer og på mobil.

Skalaen følger standarden de fleste webrammeverk bruker: én enhet er 4 px (0,25 rem), og trinnene heter det samme som i Tailwind. Utviklere kan bruke tallene direkte. De store avstandene skifter ved faste brytepunkter: mobil, lg (1024 px) og 2xl (1536 px).

I bruk

Om oss, målt opp

Seksjonen fra forsiden på 2xl-skjerm (1920 px). Etiketten står øverst i margen, innholdet starter trinn 48 under, og seksjonen slutter med trinn 72.

Regler

Slik holdes rytmen

  • Bare trinn fra skalaen

    Trenger noe mer luft, gå et helt trinn opp. Egne verdier som 40 eller 120 px gjør rytmen utydelig og koden vanskelig å vedlikeholde.

  • Nært hører sammen

    Det som hører sammen får små trinn (2 til 12). Det som skiller deler av siden får store (24 til 72). Gapet mellom de to gruppene gjør siden luftig.

  • Margen er hellig

    Alt innhold starter på samme venstrelinje. Bare bilder i full bredde og fargebånd går helt ut i kanten.

Kode

CSS-variabler

Bruker prosjektet Tailwind, finnes trinnene allerede som standard. Ellers limes dette inn i stilarket. Rollene skifter verdi ved brytepunktene.

/* J.C. Broch · spacing · 1 enhet = 4 px = 0.25rem */
:root {
  --space-2:  0.5rem;   /*   8 px */
  --space-3:  0.75rem;  /*  12 px */
  --space-4:  1rem;     /*  16 px */
  --space-6:  1.5rem;   /*  24 px */
  --space-8:  2rem;     /*  32 px */
  --space-12: 3rem;     /*  48 px */
  --space-16: 4rem;     /*  64 px */
  --space-24: 6rem;     /*  96 px */
  --space-36: 9rem;     /* 144 px */
  --space-48: 12rem;    /* 192 px */
  --space-72: 18rem;    /* 288 px */

  /* Roller, mobil */
  --marg:            1.25rem;
  --seksjon-topp:    var(--space-16);
  --etikett-innhold: var(--space-16);
  --seksjon-bunn:    var(--space-24);
  --kolonne:         var(--space-12);
}
@media (min-width: 1024px) { /* lg */
  :root {
    --marg: var(--space-16);  --seksjon-topp: var(--space-24);
    --etikett-innhold: var(--space-24);  --seksjon-bunn: var(--space-36);
    --kolonne: var(--space-16);
  }
}
@media (min-width: 1536px) { /* 2xl */
  :root {
    --marg: var(--space-36);  --seksjon-topp: var(--space-36);
    --etikett-innhold: var(--space-48);  --seksjon-bunn: var(--space-72);
    --kolonne: var(--space-36);
  }
}
